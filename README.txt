INVESTORS’ SUMMIT — WEBSITE V1.0
================================
STATUS: Implemented prototype; not deployed; official competition records pending.

HOW TO VIEW
1. Unzip the folder.
2. Double-click index.html to open the site in a browser.
3. Use the navigation to explore the pages.

HOW TO PUBLISH (STATIC HOSTING)
1. Open a free static hosting service such as Netlify Drop.
2. Upload the CONTENTS of this folder (index.html, styles.css, app.js, data.js, assets/).
3. The service will provide a public site address.
4. A custom domain and editing dashboard can be added later.

WHAT IS IMPLEMENTED
- Responsive homepage, About/Founder, Editions, 2026–2027 edition
- Three independent competition pages with Season 01 structure
- Hall of Fame, Portfolio search/filter, Media archives
- Structured content in data.js for future years, teams, awards, people, media
- Working mobile menu, hash navigation, scroll reveal, reduced-motion support
- Original user-supplied branding assets included without redrawing

WHAT STILL REQUIRES REAL CONTENT / APPROVAL
- Official transparent/vector logo (the supplied images are presentation exports)
- Founder portrait and final approved biography/message
- Verified team names, members, project descriptions, judges, committees
- Official competition results, award recipients, dates and photographs
- Approved videos and media URLs
- Confirm the inaugural seasons and academic-year mapping
- Institutional/publication approval and photo consent

IMPORTANT
All awards, photos, and statistics are intentionally NOT fabricated.
The site currently displays clearly labeled pending states.
The text in data.js can be updated as records become available.
No backend, CMS, login, payment, or database is included in V1.0.
The site uses Google Fonts via an internet connection; fallback fonts work offline.
Do not publish confidential student submissions or personal information without permission.
